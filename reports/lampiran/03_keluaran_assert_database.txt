public function test_factory_bisa_membuat_data_valid(): void

===== Interpretasi singkat ====
- assertDatabaseCount() memeriksa JUMLAH record saat test berjalan.
- assertDatabaseHas() memeriksa adanya sedikitnya satu record dengan pasangan kolom/nilai tertentu.
- Pada test 422 (harga=0), count=0 membuktikan request ditolak validasi SEBELUM controller
  menyimpan apa pun — jaminan "tidak ada data tersimpan" terekspresi sebagai assertion, bukan asumsi.
